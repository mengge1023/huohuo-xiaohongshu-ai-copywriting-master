# 火火小红书 AI 文案爆单大师

火火出品，面向小红书 AI 电商爆单陪跑营学员的文案助手。它把复杂提示词整理成清晰的素材采集和写作流程，帮助学员根据真实产品资料生成可直接修改、测试和发布的小红书笔记。

## 主要功能

提供四种写作模式：

1. **1:1 贴近仿写**：贴近对标笔记的结构、篇幅和节奏，快速生成同类内容。
2. **创新性写笔记**：保留成交逻辑，重做第一屏、场景、案例和信息组织，降低同质化。
3. **跨产品模仿**：提炼其他品类爆文的内容公式，再迁移到自己的产品。
4. **定题真人种草**：结合产品资料、同行爆款、封面和标题，生成 10 个标题及 3 篇真人感种草正文。

技能还支持读取小红书或 1688 的公开链接、整理产品卡、检查事实依据，并规避虚构经历、绝对化承诺和常见敏感表达。

## 安装方法

本技能面向 **WorkBuddy** 使用。推荐前往仓库的 Releases 页面下载已经打包好的 ZIP，然后在 WorkBuddy 的技能管理页面选择导入或安装本地技能包。

如果当前 WorkBuddy 版本要求导入解压后的目录，请先解压 ZIP，再选择下面这个完整目录：

```text
huohuo-xiaohongshu-ai-copywriting-master/
```

导入后，确认 WorkBuddy 能识别目录中的 `SKILL.md`，即可开始使用。

## 使用示例

安装后，可以在 WorkBuddy 中这样发起任务：

```text
使用火火小红书 AI 文案爆单大师，帮我根据这篇对标笔记为自己的产品写一篇小红书文案。
```

如果还没有确定模式，助手会先引导选择；如果已经提供模式和素材，则会直接进入信息采集与写作。

## 使用提醒

- 生成内容前，请尽量提供真实、完整的产品信息。
- 不要虚构产品功效、认证、销量、用户评价或个人使用经历。
- 发布前请结合具体品类与平台最新规则进行合规复核。
- 爆款需要持续测试和复盘，不承诺“必爆”或“稳赚”。
